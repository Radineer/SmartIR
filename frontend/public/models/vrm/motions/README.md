# VRM Motions

Place `.vrma` motion files here for VRM character animations.

## Required Motions

| File | Description | Source |
|------|-------------|--------|
| `idle.vrma` | Standing idle animation | Booth / VRoid Hub |
| `talking.vrma` | Talking gesture animation | Booth / VRoid Hub |
| `thinking.vrma` | Thinking pose animation | Booth / VRoid Hub |
| `happy.vrma` | Happy/excited animation | Booth / VRoid Hub |
| `wave.vrma` | Hand wave greeting | Booth / VRoid Hub |

## How to Get Motions

1. Visit [Booth](https://booth.pm/) and search for "vrma モーション"
2. Download free VRM Animation files (.vrma)
3. Place them in this directory with the filenames above

## Iris VRM Model

The iris.vrm model should be created with VRoid Studio:
- Silver-white short bob hair
- Blue iris eyes
- White lab coat
- See `docs/character-iris.md` for full specification

Export from VRoid Studio and place as `../iris.vrm`.
