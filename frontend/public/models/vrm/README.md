# VRMモデル配置ガイド

## 推奨モデル入手先

### 無料モデル
1. VRoid Hub: https://hub.vroid.com/
2. BOOTH（無料タグ）: https://booth.pm/

### VRoid Hub サンプルモデル
- **AvatarSample_A** (公式サンプル)
- URL: https://hub.vroid.com/

### つくよみちゃん（商用利用可）
- URL: https://tyc.rei-yumesaki.net/

## イリス専用モデル作成方法
1. VRoid Studio（無料）でキャラクター作成
2. 髪色: 紫〜青のグラデーション
3. 目の色: シアン
4. 服装: ビジネスカジュアル

## 配置方法
1. `.vrm`ファイルをこのディレクトリに配置
2. `src/config/vrm-models.ts` に設定追加

## 必要なファイル
- `iris.vrm` - イリスのデフォルトモデル
- `AvatarSample_A.vrm` - VRoid公式サンプル（開発用）

## 注意事項
- VRMモデルは各モデルの利用規約に従ってください
- 商用利用する場合は、ライセンスを必ず確認してください
