# Audio Resources Guide - SmartIR Remotion Video

このドキュメントでは、Remotion動画で使用するBGM・効果音のフリー素材情報と配置方法を説明します。

## ディレクトリ構造

```
public/audio/
├── bgm/                    # BGMファイル
│   └── business-calm.mp3   # デフォルトBGM
├── se/                     # 効果音ファイル
│   ├── op-appear.mp3       # OP登場音（シャキーン）
│   ├── transition.mp3      # 場面転換音（シュッ）
│   ├── emphasis.mp3        # 強調音（ポン）
│   ├── graph-display.mp3   # グラフ表示音（ピロリン）
│   └── ed-chime.mp3        # ED終了音（チャイム）
└── AUDIO_RESOURCES.md      # このファイル
```

## 1. フリーBGMサイト情報

### DOVA-SYNDROME
- **URL**: https://dova-s.jp/
- **特徴**: 18,500曲以上の無料BGM、商用利用可能、クレジット表記不要
- **おすすめカテゴリ**: 「落ち着いた」「ビジネス」タグで検索
- **ダウンロード**: 各楽曲ページからMP3形式で直接ダウンロード

#### ビジネス動画におすすめの楽曲例
- タグ「落ち着いた」+「シンプル」で検索
- ジャンル「アンビエント」「エレクトロニカ」
- テンポ90-110BPM程度の楽曲

### 魔王魂
- **URL**: https://maou.audio/
- **特徴**: 登録不要、商用利用可能、改変OK
- **おすすめカテゴリ**: BGM > ヒーリング・ニューエイジ
- **ダウンロード**: 各楽曲ページの「Download」ボタンからMP3/OGG形式で取得

#### ビジネス動画におすすめの楽曲例
- ヒーリング系BGM
- シンセサイザー系の落ち着いた楽曲

### 甘茶の音楽工房
- **URL**: https://amachamusic.chagasi.com/
- **特徴**: 500曲以上、商用利用可能、クレジット不要
- **おすすめカテゴリ**:
  - イージーリスニング
  - ニューエイジ
  - シネマティック
  - アンビエント
  - イメージ「大人な雰囲気」
- **ダウンロード**: 各楽曲の試聴画面から「ダウンロード」ボタン

## 3. 音量設定ガイド

AudioManagerコンポーネントで使用する推奨音量設定:

```typescript
export const AUDIO_VOLUME = {
  // BGM音量
  BGM_DEFAULT: 0.25,        // 基本音量（控えめ）
  BGM_NARRATION: 0.15,      // ナレーション中（さらに控えめ）
  BGM_OP: 0.4,              // OP中（少し高め）
  BGM_ED: 0.35,             // ED中（少し高め）

  // ナレーション
  NARRATION: 1.0,           // フルボリューム

  // 効果音
  SE_OP: 0.7,               // OP効果音
  SE_TRANSITION: 0.5,       // 場面転換音
  SE_EMPHASIS: 0.6,         // 強調音
  SE_GRAPH: 0.5,            // グラフ表示音
  SE_ED: 0.65,              // ED効果音
};
```

## 4. 使用方法

### 4.1 BGMの追加

1. 上記サイトからBGMをダウンロード
2. `public/audio/bgm/` に配置
3. `IRAnalysisVideo` コンポーネントの `bgmUrl` プロパティで指定

```typescript
<IRAnalysisVideo
  bgmUrl="/audio/bgm/your-bgm.mp3"
  // ...other props
/>
```

### 4.2 効果音の追加

1. 上記サイトから効果音をダウンロード
2. 以下のファイル名で `public/audio/se/` に配置:
   - `op-appear.mp3` - OP登場音
   - `transition.mp3` - 場面転換音
   - `emphasis.mp3` - 強調音
   - `graph-display.mp3` - グラフ表示音
   - `ed-chime.mp3` - ED終了音

### 4.3 カスタム効果音タイミングの追加

スクリプトにマーカーを追加することで、任意のタイミングで効果音を再生できます:

```typescript
const script = [
  {
    text: "重要なポイントです！",
    startFrame: 100,
    durationFrames: 90,
    expression: "surprised", // これがあると自動で強調音が再生される
  },
];
```

## 5. 注意事項

### 著作権・利用規約
- 各サイトの利用規約を必ず確認してください
- 商用利用可能であっても、規約は変更される可能性があります
- 必要に応じてライセンス情報を記録しておくことを推奨

### 音声フォーマット
- **推奨形式**: MP3 (Remotionで最も安定)
- **代替形式**: OGG, WAV
- **サンプルレート**: 44.1kHz推奨
- **ビットレート**: 128kbps以上推奨

### パフォーマンス
- BGMファイルは2-3MB以下を推奨
- 効果音は100KB以下を推奨
- 長時間のBGMはループ設定を活用

## 6. トラブルシューティング

### 音声が再生されない場合
1. ファイルパスが正しいか確認
2. `staticFile()` を使用しているか確認
3. ファイル形式がサポートされているか確認

### 音量バランスが悪い場合
1. AUDIO_VOLUME定数を調整
2. 元の音声ファイル自体の音量を確認
3. Audacityなどで正規化を検討

### タイミングがずれる場合
1. フレームレート(fps)を確認（デフォルト30fps）
2. 効果音の発音タイミングを調整
3. 音声ファイルの先頭の無音部分を確認
