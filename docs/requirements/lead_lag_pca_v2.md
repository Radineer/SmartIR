# 要件定義: 部分空間正則化PCA リードラグ戦略 v2 (実運用版)

## ユーザーストーリー

AS A 個人クオンツ投資家
I WANT TO 中川ら(SIG-FIN-036)の日米リードラグ戦略を実運用可能な形で実装したい
SO THAT 取引コスト・流動性を考慮した上で実際にリターンを得られる

## 背景: v1の問題点

| 問題 | 影響 | 対策 |
|------|------|------|
| TOPIX-17 ETFの流動性不足 | スプレッド50-100bps、市場インパクト大 | 個別大型株バスケットに置換 |
| 取引コスト未考慮 | 見かけのAR=23%が大幅に減る | 二次マーケットインパクトモデル導入 |
| 固定λ=0.9 | レジーム変化に対応不可 | 適応的λ (ローリングCV) |
| 単一シグナル | アルファ減衰リスク | MOM+PCA+品質ファクター アンサンブル |
| 全17セクター均等 | 弱シグナルセクターがノイズ源 | セクター選別 (IC安定性ベース) |

## リサーチから得た改善案 (優先度順)

### P1: 取引コスト現実化
- **個別株バスケット**: 各TOPIX-17セクターのトップ3-5時価総額銘柄で構成
  - スプレッド: 2-5bps (ETFの50bps→10分の1)
  - 出来高: 10-100倍
- **コストモデル**: スプレッド + 手数料(5bps片道) + 二次マーケットインパクト
- **実行**: 寄付きオークション(板寄せ)での発注

### P2: セクター選別
- 全17セクターではなく、IC安定性の高い上位8-10セクターに集中
- ローリングIC(情報係数)でセクター別にシグナル品質を評価
- IC < 0.02 のセクターは除外

### P3: アンサンブルシグナル
- PCA_SUBシグナル + モメンタム + 短期リバーサルの単純平均
- ダブルソートよりも安定したアルファ

### P4: 適応的正則化パラメータ
- λをローリングCV(過去60日のOOS R²最大化)で動的に調整
- レジーム変化時に自動追従

### P5: ポジション管理
- VIXレベルに応じたポジションサイジング
  - VIX < 20: フルサイズ
  - VIX 20-30: 50%
  - VIX > 30: 25%（ボラ高い時はシグナルが強いが執行リスクも大）
- 日経225先物ミニでベータヘッジ（セクター相対アルファの抽出）

### P6: リバランス頻度の最適化
- 毎日→週次で十分（ターンオーバー削減、コスト半減）
- シグナル変化が閾値以下なら保持継続
