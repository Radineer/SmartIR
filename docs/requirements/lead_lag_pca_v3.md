## アルゴリズム

### Step 1: 米国セクターETFのCC リターン → PCA シグナル (v1と同じ)
### Step 2: 日本側シグナル ẑ_J を集約
- composite_t = mean(ẑ_{J,t}) — 全セクターの平均予測
- z_composite = (composite - rolling_mean) / rolling_std

### Step 3: 確信度フィルター
- |z_composite| >= 1.5: ポジション取得
- |z_composite| >= 2.0: フルサイズ
- 1.5 ≤ |z| < 2.0: リニアスケール (50-100%)
- |z| < 1.5: フラット (売買しない)

### Step 4: 日経225先物で実行
- z > 0: ロング日経先物
- z < 0: ショート日経先物
- 寄りエントリー → 引けエグジット (intraday)

### Step 5: コストモデル
- 往復3 bps (スプレッド1.3bps + 手数料0.1bps + スリッページ1.6bps) × 2
